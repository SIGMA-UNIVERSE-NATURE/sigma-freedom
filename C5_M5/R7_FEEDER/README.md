# R7 Language Feeder R1

## Role

This feeder exists only to improve the quality and breadth of documents offered
to the live C5V4/R7 learner without creating another learner or writer.

```text
ROLE=FEEDER_ONLY
MODEL=NONE
AIL=NONE
VM=NONE
CANON_WRITE=NO
HEAD_WRITE=NO
R7_MUTATION=NO
HOST_ROLE=MECHANICAL_ONLY
COGNITION_OWNER=SIGMA_NATIVE
C5V4_ROLE_CONTRACT=SOLE_LEARNER_SOLE_CANON_WRITER
```

The live learner decides whether/how to learn. The feeder performs only byte
validation, content addressing, provenance serialization, deduplication, and
atomic queue handoff.

## Queue contract

For payload SHA256 `<sha>`:

```text
.sigma_sources/LOCAL_LEARNING_INBOX/
  documents/<sha>.document
  provenance/<sha>.json
  READY.manifest
  .READY.manifest.lock
```

READY.manifest record:

```text
<sha256><TAB>documents/<sha256>.document
```

The manifest is protected with `fcntl.flock(LOCK_EX)` and replaced through a
same-directory temporary file + `os.replace`.

## Feed quality target

Volume is not the objective. Prefer complete, legally usable documents that add
linguistic structure R7 can learn from:

- whole works / chapters with long-range discourse;
- narrative with dialogue, perspective shifts, intent and belief changes;
- argumentative and explanatory prose with explicit evidence/revision;
- Vietnamese natural prose with varied registers and syntax;
- multilingual documents from independent sources rather than translations
  generated by a model;
- documents whose provenance, license/source identity and exact bytes can be
  preserved;
- low-duplication material. Avoid sentence shards, templated paraphrase spam,
  benchmark answers, labels, summaries, and host-selected semantic targets.

This feeder does **not** rank semantic value. Those are sourcing guidelines for
the operator; C5V4/R7 remains the cognition/learning owner.

## Usage

Dry-run first:

```bash
python C5_M5/R7_FEEDER/R7_LANGUAGE_FEEDER_R1.py \
  /path/to/document.txt \
  --source-id SOURCE_ID \
  --source-url 'https://source.example/item' \
  --language vi \
  --title 'Exact source title' \
  --doc-type HUMAN_WRITTEN_DOCUMENT \
  --license 'PUBLIC_DOMAIN' \
  --dry-run
```

Queue after inspecting the dry-run:

```bash
python C5_M5/R7_FEEDER/R7_LANGUAGE_FEEDER_R1.py \
  /path/to/document.txt \
  --source-id SOURCE_ID \
  --source-url 'https://source.example/item' \
  --language vi \
  --title 'Exact source title' \
  --doc-type HUMAN_WRITTEN_DOCUMENT \
  --license 'PUBLIC_DOMAIN'
```

Default maximum payload is `849999` bytes to match the observed bounded R7
intake ceiling from the live transcript. The minimum is intentionally not
invented; `--min-bytes` is operator-controlled until the consumer contract
prints a stronger exact minimum.

## Non-goals

Do not add semantic summarization, semantic similarity, language understanding,
intent labels, emotion labels, answer keys, relevance ranking, lesson
generation, model calls, VM calls, AIL calls, or canonical writes to this
feeder.
