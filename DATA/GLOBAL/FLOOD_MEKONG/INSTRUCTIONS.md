# 📥 HƯỚNG DẪN LẤY DỮ LIỆU LŨ LỤT MEKONG (2006–2026)

## Nguồn dữ liệu cần tải:

### 1. Lượng mưa (NASA GPM)
- **Trang web:** https://disc.gsfc.nasa.gov/datasets/GPM_3IMERGDF_06/summary
- **Khu vực:** Sông Mekong (10°N–25°N, 95°E–110°E)
- **Thời gian:** 2006-01-01 đến 2026-07-31
- **Định dạng:** CSV hoặc NetCDF
- **Tên file sau khi tải:** `rainfall_mekong_2006_2026.csv`

### 2. Mực nước sông (MRC)
- **Trang web:** https://www.mrcmekong.org/our-work/data-and-maps/
- **Các trạm chính:** 
  - Chiang Saen (Thái Lan)
  - Luang Prabang (Lào)
  - Kratie (Campuchia)
  - Tân Châu (Việt Nam)
- **Thông số:** Mực nước (cm) và lưu lượng (m³/s)
- **Tên file sau khi tải:** `water_level_mekong_2006_2026.csv`

### 3. Dự báo thời tiết (NOAA)
- **Trang web:** https://www.cpc.ncep.noaa.gov/products/global_monitoring/
- **Tên file sau khi tải:** `noaa_forecast_mekong_2006_2026.csv`

## 📂 Sau khi tải xong, đưa các file vào thư mục `RAW_DATA`
