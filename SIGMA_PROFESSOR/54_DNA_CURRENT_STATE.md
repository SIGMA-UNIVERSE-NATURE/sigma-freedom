## Checkpoint discipline

1. create immutable checkpoint under `SIGMA_PROFESSOR/CHECKPOINTS/`;
2. update this rolling state in the same work cycle;
3. preserve exact source/bytecode/runtime hashes when evidence exists;
4. never infer missing hashes;
5. choose the next capability by dependency and capability value, not by DNA number.
