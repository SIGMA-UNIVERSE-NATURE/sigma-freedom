## Exact V1 capability contract

Native SIGMA must:
- emit exact acquisition request protocol in PREPARE;
- bind request ID, source family, resource ID and payload slot;
- validate exact response identity in VERIFY;
- retain transport-not-found visibility;
- refuse malformed/mismatched responses;
- require non-empty payload for success;
- persist acquisition provenance as source-family + resource-ID + request-ID binding;
- provide idempotency and request-ID conflict refusal;
- enforce bounded ledger capacity.

Host transport may only:
- inspect an exact emitted request event;
- look up the exact requested resource ID in the isolated fixture registry;
- copy exact fixture bytes to the requested sandbox payload slot;
- emit exact RC0 or RC_NOT_FOUND response protocol.
