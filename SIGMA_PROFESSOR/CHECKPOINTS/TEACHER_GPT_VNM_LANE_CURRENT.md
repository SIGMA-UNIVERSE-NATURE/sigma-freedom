## Proven root cause

The admitted VNM-01 standalone runner writes its scalar hypothesis ABI without a trailing newline:

```bash
printf 'HYPOTHESIS||%s||FORM_A||%s||FORM_B||%s' ... > hypothesis.memory
```

The failed VNM-04 integration parent runner routed the first bundle record using:

```bash
sed -n '1p' bundle > hypothesis.memory
```

That operation re-emits a newline terminator. Since `FORM_B` is the last `||` field, VNM-01 receives candidate B with the record-separator newline attached. Evidence observed B is an interior field and has no newline. Native exact equality therefore returns false.
