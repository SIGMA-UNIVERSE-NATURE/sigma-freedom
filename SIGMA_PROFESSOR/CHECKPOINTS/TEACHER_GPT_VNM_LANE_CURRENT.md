### Dependency decision

The admitted VNM chain currently proves three separate native capabilities:

```text
VNM-03:
delimiter-defined sequences
-> native FORM/LEFT/RIGHT observations

VNM-02:
observations
-> native recurrent pair candidate

VNM-01:
externally supplied pair hypothesis + raw evidence
-> native persistent support/competing weight update
```

The remaining gap is between VNM-02 and VNM-01. Shell/GPT must not fill this by selecting VNM-02 forms, manufacturing a VNM-01 hypothesis, or generating evidence pairs.

VNM-04 fills exactly that gap:

```text
native VNM-02 candidate
+
native VNM-03 observations
-> VNM-04 native candidate/observation consistency
-> VNM-04 native HYPOTHESIS generation
-> VNM-04 native raw EVIDENCE generation
-> one VNM-01 input bundle
-> exact mechanical line routing only
-> admitted VNM-01 native weight update
```
