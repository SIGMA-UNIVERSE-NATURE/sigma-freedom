### Runner fixture generator defect

The V1 runner `aset()` attempted to generate stale evidence using an escaped-quote shell command substitution inside an `eval` string. The comparison was effectively made against a quoted literal and evaluated false, so every intended `stale_possible=1` fixture received `stale_evidence=NONE`.

Observed consequence is exact: intended positive stale/dynamic cases were natively rejected by the correct DNA-46 source as `STALENESS_REQUIRES_EVIDENCE`, producing 24 such rejections, only 4 retained records, and no fresh-VM persistence pass.

### Post-VM oracle defect

For the explicit invalid-boolean case `dynamic=2`, the oracle counted every value other than `1` as static. Native DNA-46 correctly increments static count only when the token is exactly `0`; invalid token `2` is neither dynamic nor static. This created the sole 49/50 alignment failure.
