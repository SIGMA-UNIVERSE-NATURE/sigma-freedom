## Root cause

The admitted VNM-01 standalone runner creates its scalar hypothesis record with:

```bash
printf 'HYPOTHESIS||%s||FORM_A||%s||FORM_B||%s' "$1" "$2" "$3" > "$IN/hypothesis.memory"
```

There is deliberately no trailing newline in that VNM-01 input ABI.

The failing VNM-04 integration runner routed bundle line 1 with:

```bash
"$P/bin/sed" -n '1p' "$V4_BUNDLE" > "$V1_HYP"
```

`sed -n '1p'` re-emits the selected text record with a newline terminator. Because `FORM_B` is the last `||` field, VNM-01 `str_split(..., "||")` receives:

```text
FORM_B=<candidate_b> + trailing newline
```

while the evidence-side observed B value is an interior field with no trailing newline. Hence native equality correctly returns false and VNM-01 classifies the candidate-A/nonmatching-B pair as `COMPETING`.

The earlier mechanical assertion:

```text
BUNDLE_LINE1_EQUALS_HYPOTHESIS=YES
```

was not proof of VNM-01 scalar-ABI validity, because the audit itself reconstructed bundle line 1 using the same newline-emitting line operation. It proved routing consistency, not record-separator removal.
