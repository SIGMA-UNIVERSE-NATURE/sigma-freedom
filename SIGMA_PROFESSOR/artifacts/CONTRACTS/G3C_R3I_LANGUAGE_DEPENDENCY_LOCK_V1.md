Before R3I-A native source is considered dependency-bound, the active runtime workspace must mechanically locate or materialize the exact admitted dependency artifacts and equality-gate their source/bytecode identities against this lock.


## 6. Minimum R3I-A authoring unblock condition

A first R3I-A native source may be authored only when its exact direct input ABI is known from exact bytes. It does not need to invoke every LANG-01 capability in the first revision.

A valid minimal path is:

```text
EXACT_DIRECT_DEPENDENCIES_KNOWN=YES
ALL_DIRECT_DEPENDENCY_HASHES_VERIFIED=YES
INPUT_RECORD_ABI_FROZEN=YES
OUTPUT_STATE_ABI_PRECOMMITTED=YES
```

If R3I-A initially consumes only exact already-native structural records produced by a verified dependency, that is acceptable. Raw human text -> structural record conversion must remain a separate native capability chain and must not be filled by the host.
