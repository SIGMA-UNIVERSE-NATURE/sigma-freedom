# VISUAL QA CHECKLIST

For every asset:

## Academic
- [ ] Asset ID maps to declared VCU, Node IDs, Claim IDs and Source IDs.
- [ ] Output shows no stronger conclusion than the locked claims.
- [ ] Certainty/debate/model boundary remains honest.
- [ ] No universal-body, universal-face, fixed-identity, cultural-stereotype, free-will-proof, memory-camera, fairness=equal, conflict=violence, or scenario=prediction error.

## Pedagogy
- [ ] One primary learning objective is visually recoverable.
- [ ] The image is necessary for the learning job; no decoration-only content.
- [ ] Audience expression is appropriate without changing academic truth.

## Human representation
- [ ] Diversity without tokenism.
- [ ] Disability, age, care, conflict and identity shown with dignity.
- [ ] No family/gender/culture presented as universal default.

## Character & brand
- [ ] Exact official PNG master used as identity reference.
- [ ] HERO contains all four.
- [ ] Character role serves pedagogy.
- [ ] Logo/MOTTO are not model-generated; official assets only in controlled post.

## Technical
- [ ] 3840×2160 landscape, except research posters 2160×3840 portrait.
- [ ] sRGB, lossless PNG.
- [ ] Clean master contains no branding/text.
- [ ] Branded final uses official Logo Sigma + exact MOTTO.
- [ ] Filenames and SHA-256 recorded.

Independent QA remains separate and is required before R2 canonical release.
