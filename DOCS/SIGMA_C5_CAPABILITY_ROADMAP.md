## Critical semantic-purity correction

Audit of the V13–V17 lineage found a legacy native discourse path that explicitly maps lexical cues such as `Because`, `Although`, `If`, `When`, and `Therefore` to pre-authored semantic relation labels and uses LEFT/RIGHT clause splitting. Therefore this lineage MUST NOT be cited as proof that SIGMA learned those relations, achieved semantic understanding, or fully eliminated LEFT/RIGHT cognition.

The following claims remain valid because their admissions did not depend on those semantic labels:

- bounded Internet reading / no full ebook retention;
- delayed native long-term commit and host non-override;
- source-free native recall;
- multi-provenance identity hypothesis at the audited structural level;
- structural compact-memory compression/rehydration invariants.

## Locked capability lineage (claim-limited)

- **M1:** bounded Internet work reading + delayed native persistence + source-free recall foundation.
- **M2 / V16:** structural identity hypotheses derived from multi-provenance evidence; not semantic-relation understanding.
- **M3A / V17:** structural consolidation; compact memory retained audited structural recall invariants at ~1.4% of the full canonical snapshot.

## Next required milestone

Create a semantic-purity cleanline candidate that removes lexical semantic tables and LEFT/RIGHT discourse cognition entirely, while preserving the independently proven memory lifecycle and structural identity capabilities. Only after that cleanline passes regression should semantic relation learning be attempted from evidence/hypothesis/revision without predefined word→meaning mappings.

## Production rule

C5V3 production remains immutable during candidate admission. Capabilities are integrated into isolated candidates first; promotion/cutover is a separate gated milestone.
