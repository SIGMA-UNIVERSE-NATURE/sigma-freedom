## Locked capability lineage

- **M1:** bounded Internet work reading + delayed native persistence + source-free recall foundation.
- **M2 / V16:** native identity hypotheses derived from multi-provenance evidence; Stage-5 coherence admission PASS.
- **M3A / V17:** native structural consolidation; compact memory retained audited recall invariants at ~1.4% of the full canonical snapshot.

## Current boundary

V17 is not evidence of complete semantic compression. The next milestone is Stage 6B: compact-memory-only tests for novel reasoning, causal/relational preservation, contradiction and revision behavior, and provenance.

## Production rule

C5V3 production remains immutable during candidate admission. Capabilities are integrated into isolated candidates first; promotion/cutover is a separate gated milestone.
