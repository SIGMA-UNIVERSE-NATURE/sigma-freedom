## LAYER 4 — Σ.F174

Canonical name: `Quadratic-Exponential Capability Threshold Theorem / Model`.

Constant-k model:

`A'(t) = 2k(t-t0)A(t)`

with `A(t0)=A0` gives

`A(t) = A0 * exp(k(t-t0)^2)`.

Relative growth:

`A'(t)/A(t) = 2k(t-t0)`.

For `k>0, A0>0`, the function is symmetric around `t0`, has a global minimum/stationary point at `t0`, is strictly convex and strictly log-convex, and has no finite-time blow-up.

For a finite threshold `H>A0`, future crossing time on the `t>=t0` branch is:

`t_s = t0 + sqrt(ln(H/A0)/k)`.

**CORRECTION:** `t0` is NOT an inflection point for `k>0`; it is the symmetry center/global minimum.

**NORMALIZED verification split:**

`MATHEMATICAL_IDENTITY = V within assumptions`.

`EMPIRICAL_TECHNOLOGY_MODEL = NOT_ESTABLISHED by the formula alone`.

Non-claims: F174 is not a physical law, not proof of singularity, not proof of AI superiority, and not empirical validation of any listed application.

Canonical supportor kind: `CONDITIONAL_MATHEMATICAL_MODEL`, status `V_math + D_application`.
