# G3C PRIMARY MISSION CORRECTION — SEMANTIC R2 VS CURRENT R4

This file corrects and supersedes any broader wording in earlier checkpoint responsibility sections.

## Primary responsibility

The controlling task is:

```text
Continue training and testing the Semantic R2 candidate to determine whether it can replace the current R4 semantic core.
```

This is the first question every experiment must serve.

## Decision structure

```text
CURRENT CORE / BASELINE = R4
CANDIDATE = SEMANTIC R2
LAB = SHADOW / CANDIDATE WORKSPACE
AUTHORITY FOR AUTHORITATIVE EXECUTION = NATIVE VM09
PROMOTION = ONLY AFTER REAL EVIDENCE + EXPLICIT SIGMA ADMISSION
```

The purpose of improving tools, curriculum, semantic memory, representations, self-learning, blind tests, and no-regression mechanisms is not an independent project. Those are methods used to answer the R2-vs-R4 replacement question.

## What must be proven before R2 may replace R4

R2 must show evidence that is materially stronger than the current R4 baseline, including:

- deeper semantic understanding, not merely training-fit improvement;
- blind whole-document generalization;
- causal understanding;
- belief / false-belief understanding;
- intent and perspective understanding;
- supported-vs-unsupported inference;
- no unacceptable regression of capabilities Sigma already has;
- repeatable SIGMA-native evidence;
- no answer leakage or host-selected semantic verdict.

Build success, compilation, lower training loss, or a better single metric is insufficient.

## Operating rules

1. Continue experimentation in shadow/candidate space.
2. Let Native VM09 execute authoritative learning/evaluation.
3. Host/Bash may orchestrate mechanically only.
4. Do not hard-code the desired verdict or force Sigma to emit a preferred answer.
5. Do not revive narrow token/left-right/next-line paradigms as the semantic objective.
6. If R2 mechanisms are missing tools, improve the candidate tools rather than constraining the task to current limitations.
7. Failed mechanisms stay failed; do not promote them.
8. Successful shadow mechanisms remain shadow until blind evidence supports R2 over R4.
9. Only after that should explicit SIGMA admission be requested for any canonical cutover or ownership transfer.
