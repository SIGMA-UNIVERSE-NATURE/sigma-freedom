# SIGMA C5 Native Structural Consolidation V17

Stage-6A admission candidate. Lineage: V16 Stage-5 identity-hypothesis coherence.

Purpose: test whether SIGMA native cognition can reduce a full work-memory state to a materially smaller native recall capsule while preserving the already-admitted Stage-5 identity + multi-window provenance recall invariants.

This is deliberately **not** a claim that full semantic consolidation is solved. V17 proves only the first consolidation invariant set.

## Native-only consolidation
At EOF the candidate core itself selects one promoted identity hypothesis and a bounded representative event set grounded in that identity across provenance/process diversity. It emits:

- `native_consolidated_identity_memory.txt`
- `native_consolidated_event_memory.txt`
- `native_consolidated_memory_snapshot.txt`
- `native_consolidation_manifest.txt`

The host does not summarize, choose story facts, score meaning, or choose which entity/event survives.

## Admission
The preflight revalidates V16, deletes raw source before recall, then boots a clean isolated runtime containing only the native compact identity/event state. That runtime must recall without the ebook. The semantic-blind auditor requires grounding in the full native state, multi-window provenance, process diversity, non-adjacent span, and compact size <=35% of the full canonical snapshot.

Only the compact native snapshot is committed to the candidate long-term store.

Production C5V3 is observation-only: same PID and baseline hashes must survive unchanged.
