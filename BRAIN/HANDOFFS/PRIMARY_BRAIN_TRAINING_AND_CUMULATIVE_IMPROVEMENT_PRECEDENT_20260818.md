# PRIMARY BRAIN TRAINING + CUMULATIVE IMPROVEMENT PRECEDENT — 2026-08-18

## Governing intent

SIGMA's primary objective is not window identification. The primary objective is continuous brain training / system-level intelligence development grounded in reality and measured evidence.

Window identity, continuity, provenance, recovery and handoff are support mechanisms whose purpose is to prevent verified progress from being lost when a window, model, runtime or machine changes.

## Mandatory objective hierarchy

`TRAIN THE BRAIN -> PROVE THE DELTA -> PRESERVE THE IMPROVEMENT -> CONTINUE FROM THE IMPROVEMENT`

Window continuity serves this chain; it does not replace it.

## What counts as "better"

A newer window, newer version, longer runtime, larger codebase or stronger self-description is not evidence of improvement.

A candidate is better only when a versioned comparison against the previous verified baseline produces measurable useful improvement under the required evaluator and regression gates.

`SELF-CLAIMED_BETTER = NOT EVIDENCE`

## Cumulative learning rule

When an improvement is verified and promoted, record the parent baseline, candidate/version, evidence, measured differential result, evaluator result, regression result, rollback path and canonical promotion/state update.

That promoted state becomes the baseline inherited by later windows.

Successors must continue from the newest verified baseline and must not rebuild or rerun already verified work merely because they are new windows or lack chat memory.

Rerun/rebuild requires an explicit evidence reason such as regression signal, dependency/substrate/environment change, contradiction/new evidence, missing required evaluation, or an explicit audit requirement.

## Successor responsibility

Every successor must seek to make the system genuinely better than the inherited verified state while preserving verified guarantees. If it cannot prove an improvement, it must not claim one. If evidence conflicts or regression risk is unknown, HOLD before promotion/mutation as required.

## Continuity scope limit

After a successor has verified lineage, state and authority, it must return to the current canonical brain-training/measurement action. It must not continue expanding identity metadata unless a real continuity defect requires it.

## Current phase interpretation

The bounded SIGMA 512 measurement program is a measurement stage supporting the training objective. Completing measurement is not itself proof of intelligence evolution. Its purpose is to establish the evidence map needed to select and improve the highest-leverage cognition gaps without guessing.

## Durable principle

`EACH VERIFIED IMPROVEMENT MUST SURVIVE THE WINDOW THAT CREATED IT.`

`EACH SUCCESSOR STARTS FROM THE BEST VERIFIED STATE, NOT FROM ZERO.`
