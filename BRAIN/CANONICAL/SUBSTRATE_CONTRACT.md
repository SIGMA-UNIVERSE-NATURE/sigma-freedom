# SIGMA SUBSTRATE CONTRACT v1.0

## Principle

`SIGMA != Python != Windows != Linux != GPT != Ollama != GitHub != one machine`

A substrate is a replaceable implementation host. Canonical continuity belongs to versioned state, lineage, behavioral contracts, evidence, and governance.

## A compatible substrate MUST

1. load canonical state without silently rewriting history;
2. preserve identifiers and provenance;
3. distinguish model prior, observation, retrieved evidence, inference, and hypothesis;
4. discover actual capabilities instead of hallucinating them;
5. enforce authority separately from capability;
6. support read-after-write verification for critical state;
7. support rollback or safe refusal for incompatible migrations;
8. expose enough observability for independent evaluation;
9. preserve safe shutdown;
10. pass the canonical acceptance tests before receiving continuation status.

## A compatible substrate MUST NOT

- redefine root authority during migration;
- convert self-generated output into factual memory without evidence;
- infer PASS from filenames or self-report;
- replay external side effects during state recovery;
- make itself irreplaceable by policy.

## Reference implementation

Python is currently a reference implementation language only. It is not canonical identity.
