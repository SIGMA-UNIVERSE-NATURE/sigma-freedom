Allowed status vocabulary used here is exactly:
MACHINE_PROVEN
SOURCE_PASS_OBSERVED
SOURCE_CORRELATED_ONLY
DECLARED_ONLY
NOT_PROVEN
CONFLICTED
OUT_OF_CURRENT_LANGUAGE_SURFACE

`MACHINE_PROVEN` is reserved here for a localized current-hash machine observation. A prior report that says MACHINE_PROVEN but does not recapture the exact current compiler/VM linkage in the cited artifact is normalized to `SOURCE_PASS_OBSERVED`; that does not erase the prior PASS, it limits present provenance strength. `SOURCE_CORRELATED_ONLY` does not imply VM runtime semantics. `NOT_PROVEN` never means false or unsupported. `OUT_OF_CURRENT_LANGUAGE_SURFACE` is used only for an exact current compiler rejection of the tested source form.

For `SOURCE_SHA256`, the value is the tested SIGMA source SHA256 when the cited evidence recorded one. For report-only evidence without an underlying test-source hash, the field says `NOT_RECORDED_IN_PRIOR_ARTIFACT`; a Git blob identifier is not mislabeled as SHA256.
