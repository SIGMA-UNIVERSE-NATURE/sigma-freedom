# Known Limitations

1. generalized grammar gaps
2. runtime literal/type mappings
3. operator semantics gaps
4. precedence/associativity
5. evaluation order/short-circuit
6. coercion/type compatibility
7. exact bytecode header/version semantics
8. exact VM opcode mapping
9. stack effects/frame ABI
10. exact jump/IP/HALT/result semantics
11. malformed bytecode current-VM behavior
12. stable diagnostic/error ABI
13. complete semantic registry
14. lossless multilingual mapping
15. cognition/understanding not proven
16. public language/runtime specification readiness remains NO
