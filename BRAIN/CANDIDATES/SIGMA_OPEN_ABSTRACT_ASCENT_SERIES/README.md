## Evidence policy

- `CLAIM <= EVIDENCE`
- printed labels are not automatically machine facts;
- a reported validation pass is preserved at the exact reported scope;
- no current run is treated as reproducible without source, bytecode, toolchain hashes, raw output artifact, and repeat evidence;
- user-supplied terminal transcripts are marked as such;
- missing VM RC, source hash, bytecode hash, compiler hash, or VM hash remain `NOT_REPORTED` rather than inferred;
- no research result is promoted into general SIGMA language/runtime semantics without separate evidence;
- frozen reference data must not be silently regenerated or rewritten.
