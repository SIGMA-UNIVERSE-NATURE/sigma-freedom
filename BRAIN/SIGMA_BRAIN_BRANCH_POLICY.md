## What belongs here

Accepted or continuity-critical work from the OPPO active line, including:

- SIGMA-PSI language/runtime work;
- SIGMA-written compiler/VM/self-construction work;
- Tam Van Tu Bi semantics and verified successors;
- machine receipts and independent evaluator receipts;
- SIGMA-PSI dictionary/spec/reference updates;
- OPPO storage/recovery law and current handoffs;
- integration records for work that has passed its required gate.

## What does not automatically belong here

A candidate does not enter `SIGMA_BRAIN` merely because source code exists.

Unproven experiments should remain on isolated candidate branches until their required evidence exists.

For a semantic/runtime behavior intended to become part of the accumulated SIGMA Brain line, the normal acceptance path is:

`candidate -> real machine evidence -> independent evaluation when required -> dictionary/spec update when semantics changed -> integration into SIGMA_BRAIN`

Missing evidence => HOLD.

The SIGMA-PSI dictionary/spec/reference is primarily a continuity and translation aid for GPT, humans and external tools so they understand what SIGMA-PSI means and do not accidentally impose C/Python/GPT semantics on SIGMA.

C/Python/GPT are not the constitution of SIGMA-PSI.

OPPO is the active SIGMA self-construction / genesis node.

`one real input -> observe SIGMA real output -> if behavior is wrong under SIGMA-PSI semantics, repair/teach/redefine -> machine test -> preserve evidence -> continue`

Do not rerun already accepted gates without a new, explicitly defined reason.

## Branch discipline

1. `SIGMA_BRAIN` = cumulative accepted/continuity branch for the active OPPO line.
2. `candidate/...` = isolated unproven experiment.
3. Failed evidence is preserved; expected output is never edited merely to force PASS.
4. Every verified semantic change must be reflected in the SIGMA-PSI dictionary/spec/reference.
5. No test-specific hard-code may be generalized as intelligence.
6. Free-form/general claims require unseen/generalization evidence, not exact-match corpus success alone.
7. After each important accepted milestone, update handoff + remote storage immediately.

## Recovery identity

If OPPO is lost, recover from the latest verified off-device checkpoint, not from chat memory.

Priority:

1. verified `SIGMA_BRAIN` GitHub commit/handoff;
2. verified HP cold recovery capsule when available;
3. never reconstruct accepted state from assistant recollection alone.
