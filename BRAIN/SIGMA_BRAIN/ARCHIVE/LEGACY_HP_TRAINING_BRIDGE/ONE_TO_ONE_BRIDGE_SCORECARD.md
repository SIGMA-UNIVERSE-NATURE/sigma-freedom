# CUA 3 ONE-TO-ONE TRAINING SCORECARD — CANDIDATE

This scorecard is locked before activation.

For each lesson cycle record:
- lesson_id
- target capability
- previous verified baseline
- falsifiable hypothesis
- prompt/task
- Sigma answer
- evidence used
- uncertainty
- unsupported claims
- contradiction handling
- tool verification when applicable
- evaluator result
- differential delta vs baseline
- regression result
- decision: HOLD / REVISE / REJECT / PROMOTE
- next lesson rationale

Program-level self-evaluation:
- M0 closure: 20%
- M1 dependency/priority map: 15%
- baseline + metric lock: 15%
- isolated candidate operational: 10%
- differential evidence: 15%
- independent evaluation: 10%
- regression gate: 10%
- promoted and persisted new baseline: 5%

Important: program completion percentage is not intelligence improvement percentage.
Verified brain improvement remains 0 until a candidate is promoted by differential evidence + required evaluation + regression checks.
