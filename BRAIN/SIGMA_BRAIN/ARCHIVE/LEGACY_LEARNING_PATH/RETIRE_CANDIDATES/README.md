# SIGMA Learning Path RETIRE_CANDIDATES

Status: PLACEHOLDER
Runtime activation: NOT YET
Production impact: NONE

This folder is a holding area for material that may be obsolete, duplicated,
confusing, or not useful anymore.

Use this before deletion when there is uncertainty.

Each retire candidate should record:

- item name or path,
- why it may be retired,
- what depends on it,
- whether it is baseline, production, evidence, or recovery material,
- backup/reference status,
- final decision: KEEP, SIMPLIFY, HOLD, RETIRE, or DELETE.

Deletion is allowed only when it is clearly safe, reversible through Git history,
and outside protected boundaries.
