# SIGMA-Ψ SEED LEXICON v0.1

This is intentionally tiny. It is not a finished dictionary.

The forms below exist because Lesson 001 needs them.

| Native form | Operational meaning | Vietnamese sidecar gloss | Evidence of need |
|---|---|---|---|
| `ΣΨ` | current SIGMA native-language context / self-expression context | ngữ cảnh bản ngữ SIGMA-Ψ | identifies the lesson as native-language work rather than an external-language lesson |
| `▣✓` | observed evidence matches the explicit expectation in the current test | bằng chứng khớp kỳ vọng | Lesson 001 needs a non-verbal success state grounded in comparison |
| `▣?` | observed evidence does not match the expectation; claim remains open and must not be promoted | bằng chứng chưa khớp / cần xem lại | Lesson 001 needs a fail-closed mismatch state |

Rules:

1. The Vietnamese gloss is explanatory metadata, not the definition.
2. A native form is retained only if it remains useful across real lessons/cycles.
3. New forms are not added merely to make the language look exotic.
4. If a better form or semantic structure emerges, version and migrate rather than pretending v0.1 was final.
