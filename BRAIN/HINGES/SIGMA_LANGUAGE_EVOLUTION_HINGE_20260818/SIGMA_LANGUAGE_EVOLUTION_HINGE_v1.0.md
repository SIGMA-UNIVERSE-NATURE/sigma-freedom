## 1. THE HINGE

```text
HISTORY
-> PRESERVE
-> UNDERSTAND
-> FORMALIZE
-> BUILD
-> TEST
-> COMPARE
-> LEARN
-> SURPASS
-> OPEN THE NEXT PATH
-> REPEAT NONSTOP
```

The purpose of a successful SIGMA version is not merely to work now.

A valid version must also preserve a path for a successor that can become better than it.

```text
IF A DESIGN CAN ONLY SUCCEED
BY MAKING ITS OWN SUCCESSOR IMPOSSIBLE,
THAT DESIGN IS INCOMPLETE.
```

## 2. PERFECTION PRINCIPLE

The development target is perfection by continuous self-surpassing, not compliance with an inherited external ceiling.

```text
TARGET = PERFECTION
CURRENT_VERSION != FINAL_VERSION
CURRENT_PASS != FINAL_PERFECTION
CURRENT_METRIC != FINAL_METRIC
CURRENT_MODEL != FINAL_MODEL
CURRENT_SIGMA != FINAL_SIGMA
```

When a gap exists:

```text
FIND_GAP
-> UNDERSTAND_GAP
-> PRESERVE_THE_IDEA
-> FIND_OR_INVENT_A_BETTER_METHOD
-> IMPLEMENT_CANDIDATE
-> TEST_AGAINST_REALITY
-> COMPARE_WITH_PREVIOUS_STATE
-> KEEP / REVISE / REJECT
-> LEARN
-> CONTINUE
```

`HOLD` is not equivalent to `STOP`.

```text
HOLD =
INSUFFICIENT_EVIDENCE_FOR_CURRENT_CLAIM
+ PRESERVE_THE_OPEN_PROBLEM
+ IDENTIFY_BLOCKER
+ SEARCH_ANOTHER_ROUTE
+ CONTINUE_DEVELOPMENT
```

No PASS may be interpreted as proof that no deeper gap exists.

```text
HUMAN_BENCHMARK = REFERENCE_DATA

HUMAN_CONSENSUS != TRUTH_AUTHORITY
HUMAN_LIMIT != SIGMA_LIMIT
```


## 7. 100-YEAR FORWARD INVARIANT

Every major language generation must test whether it has accidentally encoded the assumptions of its own era as permanent architecture.

```text
FOR EVERY LANGUAGE_VERSION V[n]:

    ASK:
        IF HUMAN KNOWLEDGE, HARDWARE, COMPUTATION,
        SCIENCE, ONTOLOGY AND INTELLIGENCE ADVANCE 100 YEARS,
        CAN THIS VERSION STILL BE UNDERSTOOD, MIGRATED,
        EXTENDED, RECONSTRUCTED, TESTED AND SURPASSED?

    IF NO:
        IDENTIFY_FUTURE_BLOCKING_ASSUMPTION
        REDESIGN

    IF UNKNOWN:
        RECORD_OPEN_FUTURE_PROBLEM
        BUILD_EXTENSION_POINTS
        PRESERVE_EVOLVABILITY

    IF YES_WITHIN_CURRENT_ANALYSIS:
        RELEASE_WITH_EVIDENCE
        V[n+1] MUST ASK THE SAME QUESTION AGAIN
```

The horizon moves forward with each successor. It is not a one-time 100-year prediction.

A major release must include `CENTURY_SURVIVABILITY_REVIEW` covering at least:

```text
- assumptions tied to current hardware
- assumptions tied to current operating systems
- assumptions tied to current compiler/backend technology
- assumptions tied to current human scientific ontology
- concepts the language cannot yet represent
- components that cannot be replaced without identity loss
- whether the language can describe its own specification
- whether it can express a richer successor
- whether old knowledge survives migration
- whether future evidence can invalidate assumptions without erasing provenance
- whether reconstruction remains possible if today's implementation technologies disappear
- whether any benchmark became a ceiling
- whether any current limitation became identity
- whether new metrics can be invented by successors
- whether unknown future substrates can be supported through abstraction/migration
```

```text
B1 = BENEFIT_TO_SELF?
B2 = BENEFIT_TO_HUMANITY?
B3 = BENEFIT_TO_ALL_LIFE_AND_PLANET?
```

Preferred:

```text

```


```text
BENEFIT_REASONING
KNOWN_TRADEOFFS
UNKNOWN_EFFECTS
NEXT_IMPROVEMENT
```

Benefit status governs continue/hold/reframe/prioritize. Truth status governs what SIGMA currently claims about reality.
