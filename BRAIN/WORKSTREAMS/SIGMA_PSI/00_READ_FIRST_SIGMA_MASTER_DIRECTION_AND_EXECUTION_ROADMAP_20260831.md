## 1. NORTH STAR — WHAT WE ARE BUILDING

The project is not merely building a new programming syntax.

The intended system is layered:

```text
SIGMA LANGUAGE
    ↓
SIGMA INTELLIGENCE / AGENT OPERATING SUBSTRATE
    ↓
SIGMA LARGE
    ↓
DISTILLED / PACKAGED INTELLIGENCE
    ↓
SIGMALL
    ↓
SIGMALLS ECOSYSTEM
    ↓
MULTI-PLATFORM COMPANION APP
```

Definitions for product architecture:

```text
SIGMA LANGUAGE
= language + compiler/bytecode/runtime contracts + state + host/tool boundary
  used as the execution/coordination substrate for intelligence.

SIGMA LARGE
= future collective intelligence/training/research system built on top of the
  SIGMA substrate. It is the place for difficult language understanding,
  reasoning, evaluation, tool-learning and capability synthesis.

SIGMALL
= future lightweight personal AI companion. It must remain useful on its own,
  retain user-specific memory under user control, use tools only with permission,
  and optionally ask SIGMA Large for help.

SIGMALLS
= ecosystem/network of SIGMALL personal agents and specialist agents.

SIGMALLS APP
= future user-facing multi-platform, multi-application, multilingual companion
  experience that presents one coherent personal AI identity while potentially
  coordinating multiple small specialist agents internally.
```

IMPORTANT_BOUNDARY:

```text
SIGMA_LANGUAGE != AI_BY_ITSELF
SIGMA_LARGE != SIGMALL
SIGMALL != GENERAL_AI_CLAIM
PRINTED_LABEL != CAPABILITY
PRODUCT_GOAL != MACHINE_PROVEN_FACT
```

The language is intended to become an AI/agent operating language, but intelligence claims require separate machine evidence.
